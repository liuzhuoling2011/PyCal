概述

PyCal 是一款在本机运行的计算器与时间换算工具。应用不会收集、上传或与第三方共享你的个人信息或使用数据。

App Store Connect 营养标签对应选项为：不收集数据。

本机存储

稿纸计算器的历史记录与变量只写在你这台 Mac 上，文件位于 Application Support 下的 PyCal/calculator.json：

  • 直接分发（非沙盒）版本：~/Library/Application Support/PyCal/
  • Mac App Store（沙盒）版本：应用容器内对应的 Application Support 目录

这些文件不会离开设备。卸载应用或手动删除该目录即可清除。时间换算的输入仅用于当前会话，不会单独上传。

我们不会做的事

  • 不建立账号，也不要求登录
  • 不进行网络上传或远程同步
  • 不使用分析、崩溃统计或广告标识符
  • 不追踪跨 App / 跨网站行为
  • 不展示第三方广告，也不嵌入广告 SDK

联系我们
