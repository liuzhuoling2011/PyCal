# PyCal Codex 式浅色视觉语言

日期：2026-09-04  
状态：待实现  
范围：只改界面与交互呈现。计算引擎、时间换算逻辑、本地持久化、快捷键语义不变。

## 目标

把 PyCal 从「带边框的工具仪表盘」收成 Codex Desktop 那种浅色桌面工具：窄图标栏、一整块画布、底部 composer、操作悬停才出现。深色模式不做。功能不增不减。

## 非目标

- 深色模式、跟随系统外观的精致深色版
- 新工具、新计算能力、新换算能力
- 把计算器改成 Numi 式连续稿纸（最后一行即输入）
- 标准 Mac 工具栏 + 底边贴死的输入条

## 窗口壳

- 继续 `hiddenTitleBar`。红黄绿叠在左侧图标栏顶部，与 Codex 一致。
- 左侧固定 **52px** 图标栏，背景 `#ECECE8`，右侧一条 `rgba(0,0,0,0.07)` 细线。
- 图标栏只有三个控件，自上而下：稿纸计算器、时间转换；底部设置。选中态是 8px 圆角的浅填充 `rgba(0,0,0,0.08)`，没有色条、没有副标题。
- Hover 用 tooltip 显示「稿纸计算器 / 时间转换 / 设置」。不要「PyCal」「原生小工具箱」「工具」分组、「数据仅保存在本机」。
- 设置齿轮打开现有计算器设置（历史行数、清除未置顶），用 popover，不要再挂在导航项右侧。
- 主区是连续画布 `#F6F6F4`，不是 NavigationSplitView 宽侧栏。
- 默认窗口约 1080×720，最小约 900×600。

## 计算器

主区结构：历史列表占满画布，底部悬浮 composer。变量不占永久第三栏。

### 历史

- 安静列表，不是描边卡片。行与行之间靠 11px 内边距分开，不要矩形 stroke。
- 左：等宽公式 14pt。若有备注，公式下 11pt 次要色一行。
- 右：等宽结果 15pt medium，颜色近黑 `#1D1D1F`，不是青绿。
- 默认不显示置顶 / 备注 / 存为变量 / 删除。悬停该行才在结果左侧出现图标；删除仍为破坏性红色。「存为变量」仍打开现有命名 sheet，不是打开检查器。
- 悬停行背景 `rgba(0,0,0,0.035)`，圆角 8px。选中同理，不要描边框。
- 空状态：一句次要色说明，把焦点放到 composer。不要大图标 +「开始计算」按钮。
- 历史结果可以有千分符（`1,272`）。

### Composer

- 悬浮在画布底部，左右 16–18px、底 14–16px。白底、16px 圆角、1px `rgba(0,0,0,0.10)` 边框、很轻的阴影。
- 输入 15pt 等宽。占位符次要色。
- 有效预览以 `= 4,175,236` 出现在输入右侧，颜色 `#3D6B66`。这是界面里唯一成体系的冷色，表示「还没写入历史」。
- 右侧有「变量」文字按钮，再右侧回车提交（视觉是近黑小方钮，实际仍是 Return 提交）。
- 错误是 composer 上方一行 12pt 红色，不要进输入框内部。
- 去掉运算符速查条（`+ − × ÷ // % **` 那一行）和「↵ 保存」「历史 n/limit」常驻提示。

### 变量

- 默认收起。只通过 composer 上的「变量」打开或关闭右侧检查器。
- 检查器 220–240px，白底、12px 圆角、叠在画布上（不是 split 第三栏）。再点一次「变量」或点检查器外收起。
- 列表：名称 | 数值，等宽 12.5pt。悬停才出现复制 / 删除。顶部 `+` 走现有新建变量流程。
- 公式里直接写变量名即可引用，行为不变。
- `ans` 不再做成底部常驻提示。

## 时间转换

同一窗口壳，时间图标选中。

- 右上角：ns / ms / s 轻量分段，旁时区菜单。不要在两列里重复时区徽章。
- 左列日期、右列 Unix 时间戳，中间一条细线。没有卡片、没有 `.appCard()` 描边。
- 每列：11pt 标签 → 底边输入（16pt 等宽）→ 22pt medium 等宽结果。
- 「此刻 / 零点 / 每日末」是日期字段下的文字操作。「使用当前 / 复制」在时间戳列对应位置。
- 当前时间戳是窗口底栏，不是英雄模块：6px 状态点（实时用 `#3D6B66`，暂停用系统橙）+ 原始数字 + 复制 + 暂停。不要 32pt 青绿大字。
- **所有 Unix 时间戳（实时底栏、日期换算结果、复制到剪贴板）都不加千分符。** 写 `1756999338412`，不写 `1,756,999,338,412`。秒单位若带小数，保持现有去尾零规则。

## 视觉规范

| Token | 值 |
| --- | --- |
| 画布 | `#F6F6F4` |
| 图标栏 | `#ECECE8` |
| 纸面（composer / 检查器） | `#FFFFFF` |
| 主字 / 已提交结果 | `#1D1D1F` |
| 次要 | `#8A8A86` |
| 未提交预览 / 实时点 | `#3D6B66` |
| 分割线 | `rgba(0,0,0,0.07)` |
| 焦点 | 1px 近黑，无光晕 |
| 圆角 | 图标与行悬停 8，检查器 12，composer 16 |
| 字体 | 界面 SF Pro 11/13；公式与数字 SF Mono |

浅色专用。不引入系统 `windowBackgroundColor` / `controlBackgroundColor` 作为主表面，避免和这套暖灰画布打架。

Sheet（备注、新建变量、变量管理）保持系统表单，只把按钮强调色从青绿改为近黑或系统强调色，避免弹出层仍是旧仪表盘风格。

## 明确不变

- `ExpressionEvaluator`、变量赋值、`ans`、置顶与历史上限、本地 `calculator.json`
- 日期 ↔ 时间戳双向换算、时区、单位、暂停/重置
- `⌘N` 聚焦新计算行
