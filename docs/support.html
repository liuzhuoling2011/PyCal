如何获得帮助

PyCal 是开源的本地工具。遇到崩溃、计算错误、安装或 Mac App Store 相关问题，请到 GitHub Issues 提问，我们会在那里回复：

https://github.com/liuzhuoling2011/PyCal/issues

提交时请尽量写清：macOS 版本、是商店版还是 DMG、复现步骤，以及期望结果与实际结果。

常见说明

  • 计算历史只保存在本机，不会同步到其他设备。
  • Mac App Store 版与直接分发的 DMG 版数据目录不同，两边的历史互不可见，这是预期行为。
  • 仓库地址：https://github.com/liuzhuoling2011/PyCal
